# Controle Música Spotify

Este projeto tem como objetivo gerenciar e controlar músicas no Spotify de forma programática. Ele foi iniciado utilizando o gerenciador de dependências **Poetry**, que facilita a criação e manutenção do ambiente virtual e das dependências do projeto.

## Tecnologias Utilizadas

- **Python**: Linguagem principal do projeto.
- **Poetry**: Gerenciador de dependências e ambiente virtual.
- **API do Spotify**: Para integração e controle das músicas.

## Instalação

1. Certifique-se de ter o **Poetry** instalado. Caso não tenha, instale-o seguindo as instruções em [Poetry](https://python-poetry.org/docs/).
2. Clone este repositório:
    ```bash
    git clone https://github.com/seu-usuario/Controle_Spotify.git
    ```
3. Acesse o diretório do projeto:
    ```bash
    cd Controle_Spotify/Controle_musica_Spotify
    ```
4. Instale as dependências:
    ```bash
    poetry install
    ```
5. Ative o ambiente virtual:
    ```bash
    poetry shell
    ```

## Uso

Após configurar o ambiente, você pode executar os scripts para interagir com a API do Spotify. Certifique-se de configurar suas credenciais da API no arquivo apropriado.

## Análise do Projeto

Este projeto é uma excelente oportunidade para explorar a integração com APIs externas, como a do Spotify, e para aprender a gerenciar dependências de forma eficiente com o **Poetry**. Ele pode ser expandido para incluir funcionalidades como:

- Criação de playlists automáticas.
- Controle de reprodução em tempo real.
- Análise de dados das músicas.

Além disso, o uso do **Poetry** garante um ambiente de desenvolvimento limpo e organizado, facilitando a colaboração e a manutenção do código.
